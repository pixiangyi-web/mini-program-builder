# 小程序项目信息填写表

使用方式：用户可以直接复制本表填写，也可以上传填好的表格文件。没有确定的信息可填“待定”，需要 Codex 先代填的内容可填“先用示例”。

## 1. 基础信息

| 字段 | 用户填写 | 备注 |
| --- | --- | --- |
| 小程序名称 |  | 必填 |
| 品牌/项目名称 |  | 可与小程序名称不同 |
| 行业/业务类型 |  | 如预约、报名、课程、零售、民宿、场馆等 |
| 目标用户 |  | 用户画像、年龄、地区、消费场景 |
| 核心目的 |  | 展示、预约、下单、支付、加客服、会员等 |
| 核心转化动作 |  | 例如立即预约、提交报名、添加微信 |
| 品牌语/一句话定位 |  | 可待定 |
| 视觉关键词 |  | 如高级、自然、科技、亲子、专业等 |
| 禁忌风格 |  | 不想要的风格 |
